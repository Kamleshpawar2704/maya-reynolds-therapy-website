## ✨ Project Overview

This project is a **design-focused therapist website** created as part of the GrowMyTherapy Front-End Developer practical assignment.

The website was designed for **Dr. Maya Reynolds, PsyD, a Licensed Clinical Psychologist based in Santa Monica, California**.

The primary goal was to create a digital experience that feels:

* 🌿 Calm and grounded
* 🤍 Warm and welcoming
* 🧠 Professional and trustworthy
* ✨ Modern and design-focused
* 📱 Fully responsive across desktop and mobile

The content, visual direction, services, therapist profile, and office experience were developed around the provided Dr. Maya Reynolds profile.

---

## 🎯 Project Goals

The website was designed around four main goals:

1. **Recreate the structure and user experience of the reference website**
2. **Create a completely new visual identity for Dr. Maya Reynolds**
3. **Communicate her areas of expertise clearly and naturally**
4. **Create a responsive experience that works seamlessly across devices**

The final design combines a spacious editorial layout, soft natural colors, intentional photography, clear typography, and client-focused messaging.

## 🎨 Design Direction

The visual identity was intentionally designed around the feeling of **calm, safety, reflection, and trust**.

### Color Direction

The website uses a combination of:

* Soft sage greens
* Warm cream and neutral tones
* Deep natural green
* Subtle earthy accents

This creates a softer alternative to the typical clinical or overly medical visual style.

### Typography

Large editorial-style headings are paired with clean, readable body text to create strong visual hierarchy while keeping the content approachable.

### Layout

The layout uses:

* Generous whitespace
* Large visual sections
* Clear content hierarchy
* Rounded cards and image treatments
* Responsive grids
* Strong but understated calls to action

The intention was to make the website feel **premium without feeling intimidating**.

## 👩‍⚕️ About Dr. Maya Reynolds

The website is designed around Dr. Maya Reynolds, PsyD, a Licensed Clinical Psychologist based in Santa Monica, California.

Her practice focuses on supporting adults experiencing:

* Anxiety and panic
* Trauma and the effects of past experiences
* Burnout
* Perfectionism
* High internal pressure
* Emotional exhaustion
* Difficulty slowing down or feeling grounded

Her therapeutic approach is presented as **warm, collaborative, and grounded**, combining practical tools with space for reflection and deeper work.

---

## 🧠 Services & Areas of Focus

The website organizes the practice into three primary areas:

### Anxiety & Panic

Support for adults experiencing persistent worry, physical tension, difficulty sleeping, feeling on edge, and panic.

### Trauma Therapy

A carefully paced approach to working with both single-incident trauma and longer-standing patterns connected to childhood, relationships, and chronic stress.

### Burnout & Perfectionism

Support for professionals, entrepreneurs, and creatives experiencing high internal pressure, exhaustion, perfectionism, or difficulty maintaining a sustainable pace.

---

## 🌱 Therapeutic Approach

The website communicates the different therapeutic approaches used by Dr. Maya Reynolds, including:

* **Cognitive Behavioral Therapy (CBT)**
* **EMDR**
* **Mindfulness-based practices**
* **Body-oriented techniques**

The messaging focuses on creating a balance between practical tools, emotional understanding, safety, and deeper reflection.

## 🏡 Custom "Our Office" Section

A dedicated **Our Office** section was added as a completely new section for this project.

The section communicates the qualities of the Santa Monica practice environment:

* Quiet
* Private
* Comfortable
* Uncluttered
* Naturally lit
* Calm and grounding

It also communicates the available formats:

* In-person therapy from the Santa Monica office
* Secure telehealth for clients located in California

This section was designed to help potential clients visualize the experience of entering the practice before making contact.

## 📱 Responsive Design

The website was built with a responsive-first mindset.

### Desktop

The desktop experience uses:

* Multi-column layouts
* Large editorial typography
* Full-width imagery
* Spacious sections
* Structured navigation

### Mobile

The layout adapts for smaller screens with:

* Stacked content
* Responsive typography
* Mobile-friendly navigation
* Flexible images
* Touch-friendly buttons
* Single-column service cards
* Comfortable spacing for reading

The goal was to preserve the same calm visual experience regardless of screen size.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/maya-reynolds-therapy-website.git
```

### 2. Navigate into the project

```bash
cd maya-reynolds-therapy-website
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

### 5. Create a production build

```bash
npm run build
```

### 6. Start the production server

```bash
npm start
```
